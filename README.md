## 🖥️ 四个页面，就是全部交互

- **`/generate`** —— 生成工作台。选模态（视频/图片/音频）、填提示词、传首帧尾帧、调参数；
  右侧**实时显示**当前参数下有哪些源可用、各自的剩余额度。
- **`/tasks`** —— 任务队列。提交、排队、重试、取消，进度实时刷新。
- **`/settings`** —— Key 管理。一个平台可以填多个 key（3 个 Vidu 账号 = 3 倍免费次数），
  平台按模态分 TAB、按国内/海外分组展示；平台开关、路由策略、优先级都在这里。
- **`/stats`** —— 账本与统计。今天生成了多少、省了多少钱、哪家最稳。

## 🚀 五分钟跑起来

**前置要求：** Node.js ≥ 20（可选：Python 3.8+，用于 Edge-TTS 免费语音）

```bash
# 1. 克隆
git clone https://github.com/verylowlow/YoungMoreToken.git
cd YoungMoreToken

# 2. 安装依赖
npm install

# 3. 生成主密钥（用于加密你的 API Key，务必保密）
#    Windows PowerShell:
#     $k = New-Object byte[] 32; [Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($k); [Convert]::ToBase64String($k)
#    Linux / macOS:
#     openssl rand -base64 32

# 4. 写 .env 文件
cat > .env <<'EOF'
DATABASE_URL="file:../data/dev.db"
FREEVIDEO_MASTER_KEY="把上一步生成的密钥粘到这里"
EOF

# 5. 建库
npx prisma migrate dev --name init

# 6. 启动
npm run dev
```

打开 **http://localhost:3000**，去 `/settings` 填你的第一把 key，开薅。

> 💡 **不想装任何 key 也能立刻体验？**
> Edge-TTS 语音通道**无需 key、免费无限**。装上 Python 依赖后即可使用：
> ```bash
> pip install edge-tts
> ```

## 🧭 它是怎么挑源的？

每个任务到来时，路由器按四步走：

```
① 能力过滤    你选的参数（时长/比例/清晰度/首帧）→ 只留下"做得到"的源
② 额度过滤    剩余额度为 0、正在冷却、已停用的 key → 剔除
③ 评分排序    score = 0.5×质量 + 0.3×剩余额度 + 0.1×健康度 + 0.1×优先级
④ 选源执行    默认策略质量优先（前三名随机，避免单点打爆）；
              失败自动换下一家，最多重试 3 次
```

错误被分成六类分别处置：Key 失效 → 停用该 key；额度耗尽 → 冷却到重置；
限流 → 冷却 5 分钟；内容违规 → 直接换源；网络抖动 → 重试。
**每一种失败，都有对应的下一步，任务不会莫名其妙死掉。**

## 🏗️ 加一个平台有多容易？

适配器协议是全部设计的核心——平台差异被关进一个小文件里：

```ts
// src/providers/video/my-platform.ts
export const adapter: ProviderAdapter = {
  slug: "my-platform",
  modalities: ["video"],                 // 支持哪些模态——路由第一道过滤
  capabilities: () => ({ durations: [5, 10], ratios: ["16:9"], quality: 80 }),
  async submit(req, key) { /* 调上游，返回统一格式 */ },
  classifyError(err) { /* 告诉路由器这是什么错 */ },
};
```

然后在 `src/providers/index.ts` 里 import 一行，完事。
路由、队列、账本、加密、前端——**全部自动生效，一行都不用改**。
